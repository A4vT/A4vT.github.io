Exploit Development

zero click exploit A zero-click exploit is a type of cyber attack that doesn’t require the victim to click on anything or do anything to trigger it. Instead, it takes advantage of vulnerabilities in software or devices that automatically execute malicious actions without the user’s interaction. Remote Code Execution Remote Code Execution (RCE) is a type of cyber-attack where an attacker can run malicious code or commands on someone else’s computer or server from a remote location. General Cybersecurity

Password Spraying Password spraying is when attackers try many common passwords across many accounts, hoping to find one that works, instead of focusing on just one account with many different passwords. It avoids account lockouts by using common passwords like “123456” on multiple accounts. Living of The Land The main point of the “Living off the Land” technique is to use existing tools and software already present on a target system (like system utilities or native scripts) to carry out cyber attacks, rather than relying on malware or external tools.

OS internals

Branch Prediction Is a technique whereby the processor will guess which multiple execution sequences will be executed. Pipelining is a hardware technique commonly used to improve processor performance and is achieved by overlapping instruction execution. Compiler Vs Interpreter Compiler translate the entire program at once, which means faster execution, while Interpreter executes code line by line, offering flexibility but slower performance. Compilers catches errors after compilation, interpreters find errors as they go, stopping at the firs one, making Debugging easier but slower.
