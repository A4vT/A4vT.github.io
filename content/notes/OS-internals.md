## Branch Prediction
Is a technique whereby the processor will guess which multiple execution sequences will be executed.

## Pipelining
is a hardware technique commonly used to improve processor performance and is achieved by overlapping instruction execution.

## Compiler Vs Interpreter
**Compiler** translate the entire program at once, which means faster execution, while **Interpreter** executes code line by line, offering flexibility but slower performance.
**Compilers** catches errors after compilation, **interpreters** find errors as they go, stopping at the firs one, making Debugging easier but slower.
