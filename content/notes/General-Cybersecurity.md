## Password Spraying
**Password spraying** is when attackers try many common passwords across many accounts, hoping to find one that works, instead of focusing on just one account with many different passwords. It avoids account lockouts by using common passwords like "123456" on multiple accounts.

## Living of The Land
The main point of the "Living off the Land" technique is to use existing tools and software already present on a target system (like system utilities or native scripts) to carry out cyber attacks, rather than relying on malware or external tools.
